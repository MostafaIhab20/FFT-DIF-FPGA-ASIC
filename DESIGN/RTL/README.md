# Parameterized Radix-2 DIF R2SDF FFT: RTL Architecture Guide

This directory contains the synthesizable SystemVerilog RTL modules implementing the **Parameterized Single-Path Delay Feedback (R2SDF) Radix-2 Decimation-in-Frequency (DIF) Fast Fourier Transform (FFT)** IP core.

---

## 1. Top-Level Module Hierarchy

```
fft_top #(parameter int N = 32)
  │
  ├── fft_controller #(N)
  │     ├── Binary Sample Counter (cnt[S-1:0])
  │     ├── Inter-Stage Control Skew Pipeline (stage_sel[s], stage_tw_addr[s])
  │     ├── Pipeline Valid Shift Register (depth (N-1) + S)
  │     └── Automatic Flush Counter (flush_cnt)
  │
  └── gen_stages[s=0..S-1] : fft_stage #(N, DELAY_DEPTH, HAS_MULT, IS_TRIVIAL)
        ├── MUX A (Delay Feedback Input Steering)
        ├── delay_feedback_line #(DEPTH = N / 2^(s+1))
        ├── butterfly_radix2
        │     ├── [TARGET_FPGA=0] 4x Brent-Kung Adders/Subtractors (adder_subtractor_bk)
        │     └── [TARGET_FPGA=1] Inferred Fast Vertical Carry Chains
        │
        ├── Twiddle Unit (Conditionally Instantiated per Stage):
        │     ├── [s <= S-3] Full Complex Multiplier:
        │     │     ├── twiddle_rom #(ADDR_WIDTH = S-1)
        │     │     └── complex_multiplier
        │     │           ├── [TARGET_FPGA=0] 4x Booth Radix-4 Multipliers + Brent-Kung Adders
        │     │           └── [TARGET_FPGA=1] Inferred DSP48 Hard Slices
        │     ├── [s == S-2] Penultimate Stage Trivial MUX (W4 in {1, -j}, 0 Multipliers)
        │     └── [s == S-1] Final Stage Direct Wire Pass-Through (W2 = 1, 0 Multipliers)
        │
        ├── MUX B (Stage Output Steering)
        └── Stage Output Synchronous Pipeline Register
```

## 3. R2SDF Pipeline Operation & Steering

Each stage $s \in [0, S-1]$ operates in two alternating phases controlled by `stage_sel[s] = cnt[S - 1 - s]`:

```
                       ┌────────────────┐
                       │  Delay Buffer  │◀─────┐
                       │   (Depth D)    │      │
                       └───────┬────────┘      │
                               │               │
       stage_in ───▶[MUX A]────┴──────┐        │
                      ▲               ▼        │
                      │             ┌───┐    ┌───┐
     stage_sel ───────┴────────────▶│ + │    │ - │
                                    └───┘    └───┘
                                      │        │
                                      ▼        ▼
                                     Sum     Diff ──▶[Twiddle W]
                                      │                     │
                                      ▼                     ▼
                                    [             MUX B             ]───▶ stage_out
                                                    ▲
                                     stage_sel ─────┘
```

1. **Phase 0 (`stage_sel = 0`)**:
   - `MUX A` loads incoming samples into the delay buffer.
   - `MUX B` streams out the previous butterfly differences (multiplied by twiddle factors) stored in the delay line.
2. **Phase 1 (`stage_sel = 1`)**:
   - Incoming sample ($B$) and sample emerging from the delay buffer ($A$) are paired into the butterfly PE.
   - Sum ($A + B$) passes directly to `stage_out` through `MUX B`.
   - Difference ($A - B$) is redirected through `MUX A` into the delay buffer to be multiplied and flushed during the next Phase 0.

## 4. Multiplier Optimization & Zero-Cost Stages

In an $N$-point FFT, the final two stages require **zero hardware multipliers**:

1. **Penultimate Stage ($s = S - 2, D = 2$)**:
   - Twiddle factors are $W_4^0 = 1$ and $W_4^1 = -j$.
   - Multiplication by $-j$:
     $$(u + jv) \cdot (-j) = v - ju$$
   - Implemented using a simple 2:1 multiplexer and a 2's complement negation unit. **Saves 1 full complex multiplier (4 real multipliers).**
2. **Final Stage ($s = S - 1, D = 1$)**:
   - Twiddle factor is $W_2^0 = 1$.
   - Direct wire pass-through. **Zero logic gates, zero latency overhead.**

### Scaling Law:
$$\text{Total Multipliers} = \log_2(N) - 2$$
$$\text{Total Delay Buffer Registers} = N - 1$$
$$\text{Total Pipeline Latency} = (N - 1) + \log_2(N) + 1 \text{ clock cycles}$$

The core features fully registered inputs, inter-stage pipeline registers between every stage, and synchronous registered outputs for high-frequency ($F_{max} > 450\text{ MHz}$) timing closure on modern FPGAs and deep sub-micron ASIC nodes.
